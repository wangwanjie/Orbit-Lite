### 新名称

- 跨平台版正式命名为 **Orbit-Lite**（Orbit 的轻量跨平台版），可与 macOS 原生版 Orbit 同时安装

### 新功能

- 在线更新：每天自动检查一次新版本（可关闭），在「控制中心 › 通用 › 更新」中查看发布说明并一键安装、自动重启；更新包经签名校验
- 首次启动的使用向导：选择要启用的模块、熟悉常用快捷键、完成系统授权，之后可在「通用」页重新打开
- Windows 安装界面按系统语言显示简体中文、繁體中文或英文

### 优化

- 新的应用图标（与 macOS 原生版一致）
- 启动器结果列表的悬停选中只跟随真实的鼠标移动，光标恰好停在面板位置时打字不再跳选

### 修复

- 剪贴板面板呼出 / 收起时闪烁：毛玻璃背景与内容现在作为一个整体从屏幕底部滑入滑出，空格预览同样整窗淡入
- 启动器面板唤起 / 收起时背景先于内容出现：改为整窗淡入淡出
